    Configuration tables¶

    Every field of vessel.toml, declared tool files and deployment.toml, with its type, default and constraints. These tables are generated from AstralVessel's pydantic models when the site is built. Unknown keys are refused in every table. For what each setting does, see vessel.toml and deployment.toml.

    vessel.toml¶

    Manifest¶

    The top level of vessel.toml.

    Field Type Default Constraints
    agent AgentSection required
    tools ToolsSection table below
    sandbox SandboxSection table below
    output OutputSection table below

    AgentSection¶

    [agent]

    Field Type Default Constraints
    name str required matches ^[a-z][a-z0-9-]{0,62}$
    description str required
    version str "0.1.0"

    ToolsSection¶

    [tools]

    Field Type Default Constraints
    builtin list[str] []
    declared list[str] []

    Also checked when the file loads:

    • Every builtin entry must be one of read, grep, glob, list, bash.

    SandboxSection¶

    [sandbox]

    Field Type Default Constraints
    workdir str "/workspace"
    mounts list[Mount] []
    deadline_seconds int 600 >= 5, <= 3600
    tool_timeout_seconds int 60 >= 1, <= 600
    tool_output_chars int 20000 >= 1000, <= 200000
    dockerfile str | None none

    Also checked when the file loads:

    • dockerfile must be inside the agent folder.

    Mount¶

    An entry of [sandbox] mounts.

    Field Type Default Constraints
    source str required
    target str required
    read_only bool true

    OutputSection¶

    [output]

    Field Type Default Constraints
    files list["png" | "svg" | "csv" | "pdf"] []

    Declared tool files¶

    DeclaredTool¶

    Field Type Default Constraints
    name str required matches ^[a-z][a-z0-9_]{0,62}$
    description str required
    command list[str] required min length 1
    parameters dict[str, Any] {"type": "object", "properties": {}}
    timeout_seconds int | None none
    input "json-stdin" | "args" "json-stdin"
    scope "tools:read" | "tools:search" | "tools:files" | "tools:write" | "tools:system" | "tools:execute" "tools:read"

    Also checked when the file loads:

    • command needs at least one element.
    • The name may not repeat another declared tool or a built-in tool.

    deployment.toml¶

    DeploymentFile¶

    The top level of deployment.toml.

    Field Type Default Constraints
    node NodeSection table below
    owner OwnerSection required
    egress EgressSection table below
    executor ExecutorSection table below
    agents list[AgentEntry] []

    Also checked when the file loads:

    • Agent ids are unique.

    EgressSection¶

    [egress]

    Field Type Default Constraints
    upstream_url str | None none
    upstream_key str "env:VESSEL_UPSTREAM_MODEL_KEY"

    Also checked when the file loads:

    • upstream_url, when set, must be an http:// or https:// URL with a host and no spaces, or env:NAME with a valid variable name.

    NodeSection¶

    [node]

    Field Type Default Constraints
    project str "astralvessel" matches ^[a-z0-9][a-z0-9_-]{0,62}$
    image str "astralvessel-node:local" matches ^[^\s]+$
    bind str "127.0.0.1"
    port int 8001 >= 1, <= 65535
    public_url str | None none
    environment dict[str, str] {}
    front_subnet str "172.31.247.0/24"
    front_address str "172.31.247.10"

    Also checked when the file loads:

    • front_address must be inside front_subnet, and front_subnet must be a network address (172.31.247.0/24, not 172.31.247.1/24).
    • front_subnet must be a /28 or larger, and front_address must be in its lower half; other containers on front get addresses from the upper half.
    • public_url must be an http:// or https:// origin with no path.
    • environment names must be upper case, may not be set by the deployment itself and may not look like secrets.

    OwnerSection¶

    [owner]

    Field Type Default Constraints
    issuer str required
    client_id str required min length 1
    subject str | None none min length 1
    allowed_azp list[str] []
    accepted_issuers list[str] []

    Also checked when the file loads:

    • Every issuer must be an http:// or https:// URL with a host and no commas or spaces.

    ExecutorSection¶

    [executor]

    Field Type Default Constraints
    kernel_artifacts str | None none

    AgentEntry¶

    [[agents]]

    Field Type Default Constraints
    id str required matches ^[a-z][a-z0-9-]{0,62}$
    package str required
    sandbox SandboxProfile table below

    SandboxProfile¶

    [agents.sandbox]

    Field Type Default Constraints
    mounts list[MountGrant] []
    memory str "2g"
    cpus float 2 > 0
    pids int 512 >= 32
    scratch str "256m"
    turn_disk str | None none
    user_disk str | None none

    Also checked when the file loads:

    • Each mount must be read-only, and the targets must match the agent's [sandbox] mounts exactly.
    • turn_disk defaults to a quarter of scratch and user_disk to half; sizes look like 64m or 2g, and 0 < turn_disk <= user_disk <= scratch.

    MountGrant¶

    An entry of [agents.sandbox] mounts.

    Field Type Default Constraints
    target str required
    source str required
    read_only bool true
